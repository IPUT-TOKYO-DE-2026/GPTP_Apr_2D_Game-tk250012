# SpinQ

## ゲームの内容
マウスを回して敵を、穴に入れるアクションゲーム
残り時間と玉の数で、スコアが出るので、ハイスコアを目指せ！！
結構強く回さないとだめだよ
（プレイ中のスクリーンショットをドラッグ＆ドロップして追加する）

## 操作説明
- WASD:移動
- マウスクリック長押しで回転方向決定
- マウスを回して、パワーをチャージ
- マウスを離して打つ
